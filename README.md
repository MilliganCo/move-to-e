# MoveToE

## Описание

Небольшой системный Python-скрипт для переноса тяжёлых пользовательских каталогов с системного диска на другой диск с последующим созданием символьных ссылок.

Сценарий рассчитан на Windows и ориентирован на освобождение места на `C:` без ручного переноса каждой папки. В текущем виде список каталогов задан прямо в коде.

## Что делает

- берёт набор служебных папок из профиля пользователя Windows;
- перемещает их в `E:\UsersData`;
- создаёт `mklink /D`, чтобы программы продолжали видеть каталоги по старому пути.

## Стек

- Python
- `shutil`
- `subprocess`
- Windows `mklink`

## Статус

WIP. Это утилитарный скрипт под конкретную локальную задачу, который при необходимости можно расширить логированием, dry-run режимом и настройкой через конфиг.

## Как запускать

1. Откройте файл `move.py`.
2. Проверьте список папок и целевой путь `target_root`.
3. Запустите скрипт в Windows от имени пользователя с правами на создание симлинков.

## Ограничения

- Скрипт не делает резервную копию перед переносом.
- Ошибки доступа и конфликты уже существующих путей нужно обрабатывать вручную.
- Подходит только для Windows.
